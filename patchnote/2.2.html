投票・リマインダーを追加

AZQ BOT v2.2 パッチノート / 2026年11月8日

誰でも使える便利コマンドとして、ボタン投票の /poll と、指定時間にDMでお知らせする /remind を追加しました。あわせて、設定ファイルの保護やメンション検知の精度など、安定性まわりの修正も行いました。

新機能

投票 /poll

質問と選択肢を指定して、ボタンで投票できるパネルを作成します。選択肢は最大10個で、既定では「1つだけ選択」ですが、multi:True で複数選択も許可できます。単一選択では、もう一度別のボタンを押すと投票先を変更でき、同じボタンをもう一度押すと取り消せます。

minutes: で投票期間(最長7日)を指定すると、その時刻に自動で締め切って結果を表示します。hide:True にすると、締め切りまで票数を非表示にできます。投票の作成者は、いつでも🔒「締め切る」ボタンで早期締め切りが可能です。

例: /poll question:次の企画はどれ? options:"ゲーム大会" "映画鑑賞会" "coding night" minutes:1440

リマインダー /remind set /remind list /remind cancel

指定した時間になると、BOTがDMでお知らせします。時間の指定は 30m(30分)2h(2時間)1d(1日)1h30m(組み合わせ)のような書き方ができ、分数だけの 90 も受け付けます。最長は30日です。

リマインダーはBOT側に保存されるため、メンテナンスなどでBOTが再起動しても消えません。オフライン中に予定時刻を過ぎた場合も、起動後にその旨を添えて届きます。設定した内容は /remind list で確認し、/remind cancel で取り消せます(1人あたり20件まで)。

修正

複数サーバーでの安定性の向上

定期処理(未認証キック・チケット自動クローズ・過疎アラート・期限ロールの剥奪など)を、サーバーごとに隔離して並行実行するようにしました。従来は1つのサーバーでエラーが起きると、定期処理全体が停止して他のサーバーにも影響していました。同時実行数は環境変数 LOOP_CONCURRENCY(既定8)で調整できます。

連投ガードの強化(低負荷化)

すべてのスラッシュコマンドに、1人あたりコマンドごとの最短間隔(既定3秒、環境変数 CMD_COOLDOWN で調整)を導入しました。連投してもコマンド本体は実行されず、「あと◯秒待ってください」と残り秒数だけを返します。また /rank /ranking /leaderboard /kaso /ping など重めのコマンドは、同じサーバーで同時に1つしか実行できず、前の処理が残っているときは待つように案内して滞留を防ぎます。画像生成の同時実行数も、低コアのサーバー向けに既定で最大3スレッドに抑えました。

設定ファイルのバックアップ

サーバー設定(guilds.json)の保存時に、直前の正常な内容を guilds.json.bak として残すようにしました。ディスクの故障やプロセスの中断などで設定ファイルが壊れた場合、次回の起動時にバックアップから自動で復旧します。

メンション過多検知の精度向上

荒らし対策の「メンション過多」の判定で、同じユーザーへの重複したメンションを1つとして数えるようにしました。従来は、1つのメッセージの中で同じ人を何回メンションしても回数として数えていたため、通常の会話でも誤検知することがありました。あわせて @everyone・@here も1つとしてカウントします。

重複していたimport文を整理しました。

その他の変更

公式サイトの改善

コマンド一覧に投票・リマインダーを追加しました。また、SNSなどで共有したときの表示を整えるためのOGPタグと、検索エンジン向けのcanonical・サイトマップの整備を行いました(旧ドメインの記載を修正)。

アップデート方法

  • GitHub から最新の bot.py をダウンロードして、現在稼働中の bot.py と入れ替えて再起動してください。
  • 追加の設定は不要です。新しいスラッシュコマンドは、起動時の同期で自動的に反映されます。
  • リマインダーのデータは data/reminders.json に保存されます。サーバー設定と同じく、バックアップ時に残しておくと安心です。
