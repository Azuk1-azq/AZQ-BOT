経済機能を大幅強化(借金・仮想株・Web設定)

AZQ BOT v2.3 パッチノート / 2026年11月8日

経済(コイン)機能を大きく拡張しました。所持金が0になっても上限まで借金できる /loan、価格が1分ごとに変動する仮想株の売買ができる /stock、経済機能のすべてを一覧できる /economyinfo を追加しました。さらに、Webダッシュボードに「経済」タブを追加し、ブラウザから経済の設定ができる /economyweb も用意しました。初期所持金も 0 → 100 に引き上げています。

新機能

借金 /loan borrow /loan repay /loan status

所持金が0になっても、/loan borrow amount: で上限(既定 2,000)までお金を借りられるようになりました。借金はサーバーごとに設定できる上限までで、それ以上は借りられません。

返し方は2通り。/loan repay amount:(all で全額)で手動で返すか、/daily /work などでコインを得たときに自動で返済に回ります(返済が終わるまで、入ってきたコインから順に充当されます)。現在の借金は /loan status や /balance /profile でも確認できます。

借金の上限は /economy config debt_max: で変更でき、0にすると借金禁止になります。

仮想株 /stock list /stock buy /stock sell /stock portfolio

このBOTの中だけで動く仮想の株を売買できるようになりました。実際の金融商品は一切関係なく、サーバー内のコインで遊べます。

価格は1分ごとに変動します(ランダムウォーク方式。まれに大きく動く日も)。BOTが再起動しても、止まっていた時間分まとめて価格が進みます。変化率は「本日の始値」からの割合で、一覧では 🟢 / 🔴 で上がり下がりを表示します。

/stock buy symbol: shares: で購入、/stock sell symbol: shares:(all で全株式)で売却し、損益が表示されます。/stock portfolio で保有銘柄・平均取得単価・評価額・含み損益を一覧でき、/profile にも反映されます。

初期銘柄は AZQR(AZQテック)/ BOLT(ボルトゲームズ)/ MARQ(マルシェ食品)/ WATT(ワットエネルギー)/ GLDB(ゴールド銀行)/ COSM(コスモ宇宙開発) の6銘柄。管理者は /economy stock_add /economy stock_remove で銘柄の追加・削除(最大50銘柄)ができ、/economy config stock_enabled:False でこのサーバーの取引を無効化できます。

経済ガイド /economyinfo

そのサーバーの経済機能をすべて一覧できるコマンドです。現在の設定値つきで、収入(/daily /work /loan)、ショップ・アイテム・送金、仮想株の市況、ミニゲーム、管理者向けコマンド、他の経済BOTからの移行ガイドへの案内を表示します。「経済で何ができるんだっけ?」がこれ1つで分かります。

Webダッシュボードに「経済」タブ /economyweb

/economyweb を実行すると、Webダッシュボードの新しい「経済」タブを開けます(サーバー管理者のみ)。ブラウザから次の設定ができます。

・通貨の記号・名前 / 初期所持金 / 借金の上限
・/daily の報酬・連続ボーナス / /work の報酬と間隔
・送金(/pay)の許可と手数料 / ギャンブルの許可と賭け金上限 / 仮想株の許可

設定のほか、株市場・所持金ランキング(上位10)・アイテム一覧の確認もタブから行えます(アイテムの追加・編集はDiscordの /economy item_set から)。従来どおり /economy config でも変更でき、どちらで変更しても即座に反映されます。ダッシュボードは /web からも、管理者用ボタン「経済の設定を開く」で直接開けます。

その他の変更

初期所持金を 0 → 100 に変更

初めて経済を使う人に付く所持金を 100 に引き上げました。すぐに /work やミニゲームを始められます。既存のユーザーの所持金は変わりません。変更するには /economy config start_balance: か、Webダッシュボードの「経済」タブを使います。

コマンド一覧の整理

/help の経済セクションに /loan /stock /economyinfo /economyweb を追加し、管理者用コマンドも整理しました。

アップデート方法

  • GitHub から最新の bot.py と dashboard.html をダウンロードして、現在稼働中のものと入れ替えて再起動してください。2つのファイルは必ず同じフォルダに置いてください(ダッシュボードは bot.py と同じ場所から dashboard.html を読み込みます。dashboard.html を入れ替えない場合、「経済」タブは表示されません)。
  • 追加の設定は不要です。新しいスラッシュコマンドは、起動時の同期で自動的に反映されます。
  • 経済のデータは data/economy.json に保存されます(直前の正常な内容は economy.json.bak に残ります)。そのまま引き継がれるので、既存の所持金・アイテムは消えません。
  • 他の経済BOT(Noctalyなど)から乗り換える場合は /money migrate で移行ガイド、/money import で所持金の取り込み(CSV/JSON、プレビュー確認つき)が使えます。
