経済機能を大幅強化(借金・仮想株・ロールショップ・コインドロップ)

AZQ BOT v2.3 パッチノート / 2026年11月8日

経済(コイン)機能を大きく拡張しました。所持金が0になっても上限まで借金できる /loan、価格が1分ごとに変動する仮想株の売買ができる /stock、コインでロールを買えるロールショップ /roles、経済機能のすべてを一覧できる /economyinfo を追加しました。さらに、発言すると一定確率で約300コインがドロップし、先着1人がゲットできる機能を追加 — 過疎対策にもなります(管理者は /coindrop で手動ドロップもできます)。Webダッシュボード(/economyweb)でも、株の売買やギャンブルが誰でもできます(管理者は設定変更や所持金の操作も)。お仕事(/work)はクイズに正答して稼ぐ方式に変わり、間隔も3分ごとになりました。

新機能

借金 /loan borrow /loan repay /loan status

所持金が0になっても、/loan borrow amount: で上限(既定 2,000)までお金を借りられるようになりました。借金はサーバーごとに設定できる上限までで、それ以上は借りられません。

返し方は2通り。/loan repay amount:(all で全額)で手動で返すか、/daily /work などでコインを得たときに自動で返済に回ります(返済が終わるまで、入ってきたコインから順に充当されます)。現在の借金は /loan status や /balance /profile でも確認できます。

借金の上限は /economy config debt_max: で変更でき、0にすると借金禁止になります。

ロールショップ /roles(コインでロールを購入)

コインでロールを買えるようになりました。管理者が /economy role_add role: price: でロールを商品登録すると、メンバーは /roles でロールショップを開き、一覧から選んでその場で購入できます(支払いは所持金から)。

duration: を指定すると期限つきロールになり、期限が来ると自動で外れます(例: 30日で1,000コインの VIP ロール)。すでにロールを持っている人は永久ロールを再購入できません(期限つきは再購入可)。在庫(stock:)も設定でき、売り切れで販売終了になります。強い権限を持つロール・BOTより上位のロールは登録できません。

登録した商品は通常のアイテムとしても機能するため、/shop や /item からも買えます。削除・編集は /economy item_remove /economy item_set から。

コインドロップ(発言 → 先着1人がゲット) /coindrop

メンバーが発言すると、一定確率(既定 0.5%)で約300コインがチャンネルにドロップします(既定 250〜350コインのランダム)。「💰 コインを拾う」ボタンを先着1人が押すと、その金額がもらえます。60秒間誰も拾わないと消えます。

管理者は /coindrop で、いつでもコインを手動で落とせます(金額の指定も可能。チャンネルを指定して別の部屋に落とすこともできます)。イベントや配信中の盛り上げに便利です。

設定はすべて /economy config か Webダッシュボードの「経済」タブから変更できます。drop_enabled:(ON/OFF)drop_rate:(確率。パーミル指定で、5なら0.5%)drop_min: drop_max:(落ちる金額の範囲)drop_cooldown:(次に落ちるまでの最短間隔。既定5分)。ボタンを連打しても1人しか取れず、BOTは対象外です。

「発言したらたまにお金が落ちる」ので、チャットを見てくれる人が増え、過疎対策にもなります。

仮想株 /stock list /stock buy /stock sell /stock portfolio

このBOTの中だけで動く仮想の株を売買できるようになりました。実際の金融商品は一切関係なく、サーバー内のコインで遊べます。

価格は1分ごとに変動します(ランダムウォーク方式。まれに大きく動く日も)。BOTが再起動しても、止まっていた時間分まとめて価格が進みます。変化率は「本日の始値」からの割合で、一覧では 🟢 / 🔴 で上がり下がりを表示します。

/stock buy symbol: shares: で購入、/stock sell symbol: shares:(all で全株式)で売却し、損益が表示されます。/stock portfolio で保有銘柄・平均取得単価・評価額・含み損益を一覧でき、/profile にも反映されます。

初期銘柄は AZQR(AZQテック)/ BOLT(ボルトゲームズ)/ MARQ(マルシェ食品)/ WATT(ワットエネルギー)/ GLDB(ゴールド銀行)/ COSM(コスモ宇宙開発) の6銘柄。管理者は /economy stock_add /economy stock_remove で銘柄の追加・削除(最大50銘柄)ができ、/economy config stock_enabled:False でこのサーバーの取引を無効化できます。

経済ガイド /economyinfo

そのサーバーの経済機能をすべて一覧できるコマンドです。現在の設定値つきで、収入(/daily /work /loan・コインドロップ)、ショップ・アイテム・ロールショップ・送金、仮想株の市況、ミニゲーム、管理者向けコマンド、他の経済BOTからの移行ガイドへの案内を表示します。「経済で何ができるんだっけ?」がこれ1つで分かります。

Webダッシュボードに「経済」タブ /economyweb

/economyweb を実行すると、Webダッシュボードの新しい「経済」タブを開けます。メンバーのだれでも、次のことがブラウザからできます(すべて自分のアカウントに対する操作です)。

・株の売買: 一覧から選んで購入、保有株の全売却。評価額と含み損益も表示
・ギャンブル: コインフリップ(2倍)/ ルーレット(赤・黒は2倍、数字ぴったりは36倍)/ ブラックジャック(1人用。hit / stand で進行)
・閲覧: 株市場・所持金ランキング(上位10)・アイテム一覧。「🔄 更新」ボタンで株価を最新に更新

サーバー管理者でログインした場合は、さらに次の操作ができます。

・通貨の記号・名前 / 初期所持金 / 借金の上限 / /daily の報酬 / /work の報酬と間隔 / 送金・ギャンブル・仮想株の許可 / コインドロップの設定
・所持金の操作: メンバーを検索して、所持金の付与・減額・設定(/money コマンドと同じ。操作は管理ログに記録されます)

じゃんけん対戦(/rps)とマルチのブラックジャックは、Discordで遊びます。ダッシュボードは /web からも、管理者用ボタン「経済の設定を開く」で直接開けます。

その他の変更

お仕事(/work)のやり方を変更・間隔を3分に短縮

/work が、ボタンを押すだけで稼げる仕組みだったため、クイズに正答してはじめて報酬がもらえる方式に変更しました。出題は「計算」か「絵文字の数え」で、15秒以内に4択から正解を選びます。正答でフル報酬(従来どおり work_min〜work_max・ブースト適用)、誤答や時間切れは半額です。

あわせて、実行間隔の既定を 1時間 → 3分 に短縮しました。これまでに間隔を変更していないサーバーは、自動で3分に移行します(変更済みのサーバーはそのまま。/economy config work_cooldown: で変更できます)。

初期所持金を 0 → 100 に変更

初めて経済を使う人に付く所持金を 100 に引き上げました。すぐに /work やミニゲームを始められます。既存のユーザーの所持金は変わりません。変更するには /economy config start_balance: か、Webダッシュボードの「経済」タブを使います。

コマンド一覧の整理

/help の経済セクションに /loan /stock /roles /coindrop /economyinfo /economyweb を追加し、管理者用コマンドも整理しました。

アップデート方法

  • GitHub から最新の bot.py と dashboard.html をダウンロードして、現在稼働中のものと入れ替えて再起動してください。2つのファイルは必ず同じフォルダに置いてください(ダッシュボードは bot.py と同じ場所から dashboard.html を読み込みます。dashboard.html を入れ替えない場合、「経済」タブは表示されません)。
  • 追加の設定は不要です。新しいスラッシュコマンドは、起動時の同期で自動的に反映されます。コインドロップも既定で有効です(無効にするには /economy config drop_enabled:False)。
  • 経済のデータは data/economy.json に保存されます(直前の正常な内容は economy.json.bak に残ります)。そのまま引き継がれるので、既存の所持金・アイテムは消えません。
  • 他の経済BOT(Noctalyなど)から乗り換える場合は /money migrate で移行ガイド、/money import で所持金の取り込み(CSV/JSON、プレビュー確認つき)が使えます。
