レベル機能を追加

AZQ BOT v2.1 パッチノート / 2026年11月7日

サーバーに、レベルとランキングの機能を追加しました。発言するとXPが貯まり、ランクカードやランキングで確認できます。MEE6などの別のBOTからのレベルの移行にも対応していて、取り込む前の確認と、取り込み後の取り消しができます。

新機能

レベルとランキング /rank /leaderboard

発言するとXPが貯まり、レベルが上がるとチャンネルでお知らせします。/rank では、順位・レベル・次のレベルまでのXPをランクカードの画像で見られます。他の人を指定して見ることもできます。

/leaderboard では、レベル(XP)かメッセージ数のランキングを10人ずつ表示し、前へ・次へのボタンでページを切り替えられます。

XPは、既定では1回の発言で15〜25XPが貯まり、同じ人は60秒に1回までです。次のレベルに必要なXPの計算式はMEE6と同じです。

XP・レベル・ステータスの管理 /xp /level /stats

3つのコマンドに、それぞれ add(追加)remove(削除)set(設定)transfer(ユーザー間の移行)があります。ステータスは、サーバーでの累計メッセージ数です。

使えるのは「サーバーの管理」権限を持つ人だけです。変更はログチャンネルに記録されます。

他のBOTからの移行 /level migrate /level import

/level migrate で、移行元のBOTごとの手順を確認できます。取り込みは /level import で行い、実行すると人数と上位5人のプレビューが表示されます。内容を確認してから、「上書き」か「高い方を採用」を選んで取り込みます。

移行元は、MEE6(リーダーボードを公開にしておくと自動で取得)、Amari(APIキーが必要)、CSV・JSONファイル(Lurkrなどのエクスポートに使えます)から選べます。ファイルは id の列と、xp または level の列があれば読み込めます。

取り込む前の状態は自動でバックアップされ、/level undo_import で元に戻せます。取り込み後に貯まったXPも、一緒に元へ戻ります。

レベルの設定 /level config

XPの獲得そのもののON/OFF、レベルアップの通知とその送信先、1回の獲得XP(最小・最大)、獲得の間隔、通知の文面を変更できます。通知の文面では {user} {level} {server} が使えます。項目を指定しないで実行すると、現在の設定を表示します。

変更

/help と /about の表記

レベルとランキング、XPの管理、他のBOTからの移行の説明を追加しました。

サーバー管理者への注意

  • 導入直後は、全員のXPが0から始まります。以前のレベルBOTのデータを引き継ぐ場合は、/level migrate の手順で取り込んでください。
  • 元のBOTは、取り込みのあとに停止または無効化してください。動かしたままだと、2つのBOTからXPが入り、数字が食い違います。
  • MEE6から取り込むには、MEE6側でリーダーボードの公開が必要です。非公開のままだと、取り込めません。
  • レベルアップの通知には、送信先のチャンネルで「メッセージを送信」の権限が必要です。権限がない場合、通知は送られません(XPは貯まります)。
  • XPと一緒に保存するのはメッセージの件数だけです。メッセージの本文は保存しません。

自分でbotをホスティングする人向け

  • bot.py を入れ替えてください。dashboard.html の入れ替えは不要です。入れ替えたあとは、BOTを再起動してください。
  • データは levels.json に保存されます。取り込み前のバックアップは level_backup フォルダに入ります。データの保存先(DATA_DIR)を消さないように注意してください。
  • 追加の設定は不要です。新しいスラッシュコマンドは、起動時の同期で自動的に反映されます。
