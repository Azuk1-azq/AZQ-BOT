機能

🛡️ 荒らし対策
連投・同一メッセージ・メンション爆撃・招待リンク・NGワード・レイド(大量参加)を自動検知し、削除やタイムアウトを行います。
📊 過疎検出
/kaso でサーバーの活発度を診断。しきい値を下回ると自動アラートも可能です。
🧠 脳内メーカー
/nounai で名前から脳内を表示。ユーザーの右クリックからも使えます。
🖼️ 名言画像
/meigen やメッセージの右クリックで、アイコンと@IDつきの名言画像を作成します。
🏓 ping
/ping でBOTの応答速度、/ping target:ドメイン でWebサイトの応答時間を測定します。
🔨 モデレーション(管理者のみ)
kick / ban / timeout / warn / purge / lock / slowmode / ロール操作、ログ・ウェルカム・自動ロール。

必要な特権インテントと理由

Discord Developer Portal で有効化が必要な特権インテントは次の2つです(Presence Intent は使いません)。

インテント利用目的
Server Members Intentメンバーの参加・退出の検知(ウェルカム、自動ロール、レイド検知、参加ログ)と、過疎診断でのメンバー数の集計のため。
Message Content Intent荒らし対策のためのメッセージ本文の判定(NGワード・招待リンク・連投・同一投稿)と、メッセージの編集・削除ログのため。

導入時の注意

上の導入URLは管理者権限を要求します。必要な権限だけに絞って導入することもできます。BOTのロールは、管理対象のロールより上に配置してください。コマンドの一覧は /help で確認できます。
