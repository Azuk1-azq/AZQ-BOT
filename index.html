サーバー管理に必要な機能

自動で動くものと、コマンドで使うものがあります。

🛡️ 荒らし対策

連投・同一メッセージ・メンション爆撃・招待リンク・NGワード・レイド(大量参加)を自動検知し、削除やタイムアウトを行います。

連投同一投稿メンション爆撃招待リンクNGワードレイド検知

📊 過疎検出

/kaso でサーバーの活発度を診断。しきい値を下回ると自動アラートも可能です。

🧠 脳内メーカー

/nounai で名前から脳内を表示。ユーザーの右クリックからも使えます。

🖼️ 名言画像

/meigen やメッセージの右クリックで、アイコン付きの名言画像を作成します。

🏓 ping

/ping でBOTの応答速度、/ping target:ドメイン でWebサイトの応答時間を測定します。

🔨 モデレーション(管理者のみ)

ログ・ウェルカム・自動ロールの設定にも対応。コマンド一覧は /help で確認できます。

kickbantimeoutwarnpurgelockslowmodeロール操作

安心して使うための情報

BOTが何を見て、何を保存するのかを公開しています。詳細はプライバシーポリシーをご覧ください。ソースコードはGitHubで公開しているオープンソースなので、動作を自分で確認できます。

保存するもの

  • ログ・ウェルカム・自動ロール・荒らし対策などのサーバー設定
  • /warn で記録した警告(理由・実行者・日時)

保存しないもの

  • メッセージ本文のデータベース保存はしません(荒らし判定のため、直近の投稿を短時間メモリ上で扱うだけです)
  • DMの内容は読みません

知っておいてほしいこと

管理者がログチャンネルを設定した場合、削除・編集されたメッセージの内容がそのチャンネルに投稿されます。ログチャンネルは管理者だけが見られる場所にすることをおすすめします。

必要な特権インテント

Server Members Intent

メンバーの参加・退出の検知(ウェルカム、自動ロール、レイド検知、参加ログ)と、過疎診断でのメンバー数の集計のため。

Message Content Intent

荒らし対策のためのメッセージ本文の判定(NGワード・招待リンク・連投・同一投稿)と、メッセージの編集・削除ログのため。

よくある質問

ロールの順位はなぜ大切ですか?

Discordの仕様で、BOTは自分より上位のロールを持つメンバーを操作できません。キック・BAN・タイムアウト・ロール付与が失敗するときは、まずBOTのロール位置を確認してください。

荒らし対策を止めたい、または調整したいときは?

/config automod_set で検知の厳しさを変更でき、enabled を 0 にすると無効化できます。管理者・メッセージ管理権限を持つ人は検知の対象外です。

コマンドは誰でも使えますか?

kick・ban・warn などのモデレーション系と設定は管理者のみです。/kaso /nounai /meigen /ping /userinfo などは誰でも使えます。

/ping でWebサイトの測定は安全ですか?

内部ネットワークなどの非公開アドレスは測定できないようにしています。リダイレクトも追跡しません。
