Features

サーバー管理に必要な機能

自動で動くものと、コマンドで使うものがあります。

01 — AUTOMOD

荒らし対策

連投・同一メッセージ・メンション爆撃・招待リンク・NGワード・レイド(大量参加)を自動検知し、削除やタイムアウトを行います。

連投同一投稿メンション爆撃招待リンクNGワードレイド検知
02 — VERIFICATION

メンバー認証

参加したメンバーに認証を行わせ、通過した人だけにロールを付与します。/verify setup で設置でき、荒らし・BOT対策に使えます。

ボタン認証計算認証画像CAPTCHA未認証ロールアカウント年齢制限未認証キックレイド時に自動強化ロボット確認の強化Web認証(BOT自身が配信)VPN・プロキシの回線を排除同じ回線のサブ垢を検出サブ垢の疑いを検出(デフォルトアイコン・再参加・集団参加)
03 — SUPPORT

サポートチケット

パネルのボタンから、スタッフとだけ話せる非公開チャンネルを自動作成。クローズは作成者・スタッフ・管理者が行え、削除できるのは管理者のみです。

非公開chの自動作成担当者の設定記録(.txt)の保存・DM無操作で自動クローズ認証との連携
04 — ROLES

ロールパネル

ボタンを押すだけでロールを付与・解除できるパネルを設置できます。/rolepanel create で作成し、設定は管理者のみ。

ボタンで付与/解除1つだけ選択モード最大25ロール認証前は利用不可

そのほかの機能

DIAGNOSIS

過疎検出

/kaso でサーバーの活発度を診断。しきい値を下回ると自動アラートも可能です。

FUN

脳内メーカー

/nounai で名前から脳内を表示。ユーザーの右クリックからも使えます。

FUN

名言画像

/meigen やメッセージの右クリックで、アイコン付きの名言画像を作成します。他の人のアイコン・名前を使うには本人の許可が必要で、管理者はサーバー内で無効にもできます。

UTILITY

ping

/ping でBOTの応答速度、/ping target:ドメイン でWebサイトの応答時間を測定します。

RELIABILITY

再起動後も安心

メンテナンスなどでBOTが再起動しても、認証・チケット・ロールパネルのボタンはそのまま使えます。オフライン中にパネルが消えていた場合は、起動時に自動で再設置します。

MODERATION

モデレーション(管理者のみ)

ログ・ウェルカム・自動ロールの設定にも対応。/userinfo /serverinfo /avatar の情報コマンドもあります。コマンド一覧は /help で確認できます。

Trust

安心して使うための情報

BOTが何を見て、何を保存するのかを公開しています。詳細はプライバシーポリシーをご覧ください。ソースコードはGitHubで公開しているオープンソースなので、動作を自分で確認できます。

保存するもの

  • ログ・ウェルカム・自動ロール・荒らし対策などのサーバー設定
  • /warn で記録した警告(理由・実行者・日時)
  • メンバー認証の設定と、認証待ちメンバーの参加時刻
  • Web認証の「同じ回線の判定」を有効にした場合のみ、IPアドレスから作った元に戻せない値(ハッシュ)と、そのIPで認証したユーザーID(生のIPアドレスは保存しません)
  • 認証でキックした人・疑わしいと判断した人のユーザーID(再参加や集団参加の検出用。上限あり)
  • ロールパネルの設定(パネルの場所と対象ロール)
  • 名言画像の使用許可の設定(ユーザーIDと、許可する/しないの選択)
  • チケットの設定と、開いている(またはクローズ済みで削除待ちの)チケットの作成者・件名・担当者

保存しないもの

  • メッセージ本文のデータベース保存はしません(荒らし判定のため、直近の投稿を短時間メモリ上で扱うだけです)
  • DMの内容は読みません

知っておいてほしいこと

管理者がログチャンネルを設定した場合、削除・編集されたメッセージの内容がそのチャンネルに投稿されます。ログチャンネルは管理者だけが見られる場所にすることをおすすめします。

チケットをクローズすると、そのチケット内の会話の記録(.txt)が管理者の指定したチャンネル(未指定ならログチャンネル)に送信され、設定によっては作成者にもDMで届きます。記録の送信先も管理者だけが見られる場所にしてください。BOT自身は記録ファイルを保存しません。

必要な特権インテント

Server Members Intent

メンバーの参加・退出の検知(ウェルカム、自動ロール、レイド検知、参加ログ)と、過疎診断でのメンバー数の集計のため。

Message Content Intent

荒らし対策のためのメッセージ本文の判定(NGワード・招待リンク・連投・同一投稿)と、メッセージの編集・削除ログのため。

FAQ

よくある質問

キーワードで絞り込めます。

メンテナンスなどのお知らせはどこで見られますか?

メンテナンス・障害・アップデートのお知らせは、サポートサーバーでのみ配信しています。参加していないとお知らせを受け取れないので、導入後は参加をおすすめします。

ロールの順位はなぜ大切ですか?

Discordの仕様で、BOTは自分より上位のロールを持つメンバーを操作できません。キック・BAN・タイムアウト・ロール付与が失敗するときは、まずBOTのロール位置を確認してください。

荒らし対策を止めたい、または調整したいときは?

/config automod_set で検知の厳しさを変更でき、enabled を 0 にすると無効化できます。管理者・メッセージ管理権限を持つ人は検知の対象外です。

コマンドは誰でも使えますか?

kick・ban・warn などのモデレーション系と、認証・チケットの設定は管理者のみです。/kaso /nounai /meigen /ping /userinfo などは誰でも使えます。チケット内の /ticket close は作成者とスタッフも使えますが、/ticket delete は管理者のみです。

チケットは誰が閉じて、誰が削除できますか?

クローズは、チケットを作った本人・スタッフロールのメンバー・管理者ができます。クローズすると記録が保存され、チャンネルは閲覧のみになります。チャンネルの削除は管理者だけが行えます(クローズ済みのチケットに付く「削除」ボタン、または /ticket delete)。

自分のアイコンを名言画像に使われたくありません

他の人があなたのアイコン・名前で名言画像を作ろうとすると、BOTからあなたにDMが届き、ボタンで「許可する」「許可しない」を選べます。選ぶまでは作成されません。あとから /meigenprivacy でも変更できます。サーバー管理者は /config meigen で、そのサーバー全体の名言画像をOFFにできます。

ロールパネルは誰でも作れますか?

パネルの作成・編集は管理者のみです。メンバーはパネルのボタンを押してロールを付与・解除できます。管理者権限などの危険な権限を持つロールはパネルに設定できず、メンバー認証を終えていない人は利用できません。BOTのロールが対象ロールより下にあると付与に失敗するので、ロール順位を確認してください。

Web認証では、IPアドレスを取得しますか?

Web認証を使うサーバーでは、認証ページを開いたときにBOTが接続元のIPアドレスを一時的に使います。外部のサービスにIPを送ることはありません。VPN・プロキシ・データセンターの回線かどうかは、公開されているIPアドレスの一覧と照合して、BOTの中だけで判定します。「同じ回線から別のアカウントが認証していないか」の判定を有効にしたサーバーでは、IPアドレスをそのままではなく、元に戻せない値(ハッシュ)にして保存します。いずれも推測による判定なので、学校・会社・家族で同じ回線を使っている場合などに、承認待ちになることがあります。管理者はいつでも保存した値を削除できます。

メンバー認証とは何ですか?

参加したメンバーがボタン・計算・画像CAPTCHAのいずれかを通過すると、認証ロールが付与される機能です。アカウント作成からの日数制限や、時間内に認証しない人のキック、レイド検知時の自動強化も設定できます。認証が必要なチャンネルの権限設定は、設置時のメッセージの案内に沿って行ってください。

/ping でWebサイトの測定は安全ですか?

内部ネットワークなどの非公開アドレスは測定できないようにしています。リダイレクトも追跡しません。
