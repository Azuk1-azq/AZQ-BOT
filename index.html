サーバー管理機能を追加

AZQ BOT v1.9 パッチノート / 2026年10月26日

Discordサーバーの管理者向けに、役職の権限管理、参加申請・スタッフ応募、ロール管理、ポイント、管理ログをまとめて追加しました。コマンドのほか、/web から開くブラウザ画面でも操作できます。Webダッシュボードのデザインも新しくなりました。

新機能

役職と権限 /manage rank_set

管理者・副管理者・幹部・モデレーター・一般スタッフの5つの役職を、Discordのロールに対応づけられます。機能ごとに必要な役職は /manage perm_set で変更でき、/manage perm_list で一覧を確認できます。

サーバーオーナーとDiscordの管理者権限を持つ人は、常に管理者として扱われます。

参加申請とスタッフ応募 /apply setup /staffapp setup

パネルから参加申請とスタッフ応募を受け付けます。承認と却下はボタンで行い、却下には理由を付けられます。結果は申請者にDMで届き、承認するとロールが自動で付与されます。

履歴は /apply history と /staffapp history で確認できます。スタッフ応募の役職ごとのロールは /staffapp position で設定します。

ロール管理 /manage role_set

管理するロールに名前を付けて登録し、role_grant でメンバーに付与します。日数を指定すると、期限が来たときに自動で外れます。外すときは role_revoke を使います。

role_list で登録ロールと期限つきの付与を、role_history で変更履歴を確認できます。都道府県ロールは /region create と /region panel で作れます。

ポイントとランキング /points /ranking

/points add remove undo show history config mvp でポイントを管理します。/ranking では週間・月間・累計の順位を見られます。

付与の上限があり、二重付与と相互付与は防止されます。指定したチャンネルでの発言に、自動でポイントを付ける設定もあります。

管理ログ /manage log

処罰・認証・参加退出などの管理ログを表示できます。ログはBOTを再起動しても残ります。チケットの対応履歴は /manage ticket_history で確認できます。

Webのサーバー管理ページ

/web を実行すると表示される「サーバー管理を開く」ボタンから、上の機能をブラウザで操作できます。役職を持っている人だけが開けます。

変更

Webダッシュボードのデザインを刷新

項目一覧と内容を並べる2カラムにし、スマホでは項目が横スクロールの切り替えに変わります。ブラウザの設定に合わせて、ダークとライトを自動で切り替えます。保存・変更検知・ロールパネルなどの機能は変わりません。

/help の表記

役職・権限、申請・応募、ロール管理、ポイント、ログの説明を追加しました。

サーバー管理者への注意

  • BOTに「ロールの管理」権限が必要です。付与するロールよりも、BOTのロールを上に置いてください。順位が下だと、ロールを付与できません。
  • 申請の結果はDMで届きます。申請者がDMを受け取れない設定の場合は、承認や却下のあと、直接伝えてください。
  • 管理者権限を持つ人は、常に管理者の扱いです。管理者の役職に割り当てたロールを持つ人は、BOTの全機能を操作できます。ロールの付与権限は慎重に管理してください。

自分でbotをホスティングする人向け

  • bot.py と dashboard.html を入れ替えてください。入れ替えたあとは、BOTを再起動してください。
  • データは server_admin.json に保存されます。データの保存先(DATA_DIR)を消さないように注意してください。
  • 追加の設定は不要です。新しいスラッシュコマンドは、起動時の同期で自動的に反映されます。
